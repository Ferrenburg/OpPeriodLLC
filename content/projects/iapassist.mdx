An Incident Action Plan has to get written whether the incident is a planned event or a storm that's already here. A lot of that time goes to typing the same kinds of information over and over.

IAPassist is built to cut that down, so emergency managers spend less time typing and more time on the plan itself.

IAPassist is ready to use now at [iapassist.opperiod.com](https://iapassist.opperiod.com). If you have questions about it, [get in touch](/contact?project=iapassist).
